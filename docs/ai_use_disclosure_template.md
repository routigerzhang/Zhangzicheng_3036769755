# AI-use disclosure draft

This project used AI assistance for:

- organizing the replication workflow;
- translating the paper's variable definitions into executable code;
- checking sample counts and comparing generated results with the published tables;
- drafting documentation and comments.

The researcher remains responsible for verifying every data choice, sample rule,
statistical method, interpretation, and conclusion.

Before submission, complete this file with:

1. the AI tools and dates used;
2. the specific code or writing tasks assisted by AI;
3. how generated code was checked independently;
4. important AI suggestions that were corrected or rejected;
5. any remaining limitations or unverified assumptions.
